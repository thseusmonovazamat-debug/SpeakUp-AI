# SpeakUp AI

SpeakUp AI is an AI-powered English learning platform designed for Uzbek-speaking learners.

## About the Project

The goal of SpeakUp AI is to help users practice English, identify their mistakes, and understand clear explanations in Uzbek.

The project is currently under development. The responsive landing page is complete, and interactive JavaScript features are being added step by step.

## Current Features

- Responsive landing page
- Mobile navigation menu
- Platform features and pricing sections
- Student progress overview
- Teacher tools section
- Registration form interface

## Technologies

- HTML5
- CSS3
- JavaScript
- Git and GitHub

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/thseusmonovazamat-debug/SpeakUp-AI.git
```

2. Open the project directory:

```bash
cd SpeakUp-AI
```

3. Open `index.html` in your browser.

No external libraries or additional installation steps are currently required.
